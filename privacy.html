Privacy Policy

Madrid Analytics Uploader · Last updated: November 9, 2026

This Privacy Policy explains how Madrid Analytics Uploader (the "Uploader") accesses, uses, stores and deletes information. The Uploader is a private, internal tool used only by the owner of the Madrid Analytics YouTube channel to publish the channel's own videos.

YouTube API Services

The Uploader uses YouTube API Services. By using the Uploader you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

Information we access

With the channel owner's OAuth authorization, the Uploader accesses only the owner's own YouTube channel, using these permissions:

  • youtube.upload – to upload the channel's own videos;
  • youtube – to set thumbnails, update video titles and descriptions, add videos to playlists and read basic channel information (channel name and ID).

The Uploader does not access, collect or store any data about other YouTube users, viewers, subscribers or commenters, and does not download or redistribute any YouTube content.

How information is used

Information is used only to upload and manage the channel owner's own videos on the Madrid Analytics channel. It is not used for advertising, profiling, analytics resale or any other purpose.

Sharing

No information is sold, shared, disclosed or transferred to any third party. The Uploader does not use cookies or tracking technologies.

Storage and security

The only stored item is the OAuth refresh token for the channel owner's account. It is stored as an encrypted secret in a private GitHub repository and is never made public. No YouTube API data (such as video or channel metadata) is stored beyond the duration of a single upload run.

Data retention and deletion

  • Temporary data handled during an upload run is discarded when the run ends.
  • Access can be revoked at any time from Google security settings (third-party access). When access is revoked, the stored refresh token stops working and is deleted from the repository secrets within 7 days.
  • Any data obtained from YouTube API Services is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.
  • To request deletion of any data, email realmadrid.analytics@gmail.com; requests are handled within 7 days.

Changes

Any changes to this policy will be posted on this page with an updated date.
