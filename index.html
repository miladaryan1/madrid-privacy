Madrid Analytics

Privacy Policy · Last updated: November 9, 2026

Madrid Analytics is a personal tool used only by the owner of the Madrid Analytics YouTube channel to upload videos to that channel through the YouTube Data API.

Information we access

The app only requests permission to upload and manage videos on the owner's own YouTube channel. It does not access, collect, or store data from any other user.

How information is used

Access is used only to upload video files, titles, descriptions, and thumbnails to the owner's channel.

Sharing

No data is sold, shared, or transferred to third parties.

Storage and security

Authorization credentials are stored as encrypted secrets and are never made public.

Google API Services

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.
